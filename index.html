Installation & support

Settle in.

How do I install Verdant?
  1. Open the APK download page above.
  2. Under Assets, select the file ending in .apk. The Source code ZIP files are not Android installers.
  3. Open the downloaded APK. If Android requests it, allow that browser or file manager to install unknown apps.
  4. Complete installation, open Verdant and hold your phone in landscape.

Permission names vary between phones. You can switch the install permission off again afterwards.

How do I install a future update?

Download the newer APK and install it over the existing app. Updates need the same Android package identifier and signing key, with an appropriate version code. Avoid uninstalling first, as uninstalling can remove local saves. If Android rejects an update, contact the developer before removing the existing game.

Android shows a warning. What should I do?

A permission prompt for installing from your browser can appear for APKs downloaded outside an app store. If Play Protect flags the file as harmful, stop and send the warning to the developer for investigation.

Can I play in my browser or on iPhone?

This download is an Android APK. A browser-playable edition and an iPhone release are not provided here.
